## 📁 Projects

### 🔍 1: Exploratory Data Analysis (EDA) on Retail Sales `Retail_sales_P1`

**📌 Description:**  
This project focuses on examining and interpreting retail sales data to uncover patterns, trends, and insights. The analysis includes:

- Customer demographics  
- Purchasing habits  
- Product popularity  
- Time-based buying trends  

These insights assist the business in making data-driven strategic decisions.

**🛠 Programming Language & Libraries:**  
`Python`, `Pandas`, `Matplotlib`, `Seaborn`

📂 **Dataset File:** `retail_sales_dataset`

### 🏙️ 2: New York Airbnb - Data Cleaning Project `NYC_P2`

**📌 Description:**  
This project involves cleaning a New York Airbnb dataset to ensure high data quality for analysis and modeling. Key cleaning steps include:

- **Missing Data Resolution:** Imputing or removing missing values  
- **Duplicate Handling:** Identifying and removing duplicate entries  
- **Format Standardization:** Standardizing variable formats  
- **Outlier Management:** Detecting and handling outliers

**🛠 Programming Language & Libraries:**  
`Python`, `Pandas`, `NumPy`

📂 **Dataset File:** `AB_NYC_2019`
